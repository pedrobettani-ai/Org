# Organograma PhizChat

Organograma interativo das BUs PhizChat (Brasil e China), publicado pelo GitHub Pages.

## Como abrir

Acesse o endereço do GitHub Pages deste repositório. O site abre direto, sem senha.

## Como atualizar

1. Abra o site e faça as edições (clique em ✎ para editar, arraste para mudar o reporte, “+ Nova caixinha” para adicionar).
2. Clique em **Baixar index.html**.
3. Neste repositório, use **Add file → Upload files**, arraste o `index.html` e confirme o commit.
4. Em um ou dois minutos o site mostra a nova versão.

## Atenção

O repositório e o site são públicos: qualquer pessoa com o link vê nomes, cargos e vagas. Para restringir o acesso, o organograma também consegue gerar uma versão cifrada com frase-chave (Exportar → Versão protegida para o GitHub). Antes de trocar para ela, apague esta versão aberta do histórico do repositório.
